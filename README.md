# 📈 Zerodha AI — Financial Intelligence Platform

**AI-powered stock market analytics platform** — Live data + RAG + Multi-agent system + Streamlit

---

## 🚀 Overview

An end-to-end AI platform that:
- Fetches live stock data (NIFTY 50 stocks)
- Analyzes trends and volatility
- Answers questions about financial documents using RAG
- Uses multi-agent AI to write market summaries
- Deploys as an interactive web dashboard

---

## 🛠️ Tech Stack

| Layer | Tools |
|---|---|
| Data | yfinance, SQLite, Pandas |
| LLM | Groq API (Llama 3.3) |
| RAG | LangChain, ChromaDB, HuggingFace Embeddings |
| Agents | CrewAI, LangGraph |
| Frontend | Streamlit, Plotly |
| Deployment | Streamlit Cloud |
